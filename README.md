# TeacherCollab research project page

Static research project website for [TeacherCollab](https://teachercollab.github.io).

## Preview locally

From this directory, run:

```bash
python3 -m http.server 8000
```

Then open <http://127.0.0.1:8000>.

The site uses plain HTML and CSS and does not require a build step.

## Publish

Push the repository to `teachercollab/teachercollab.github.io`. In the repository’s
GitHub Pages settings, select **Deploy from a branch**, then choose `main` and `/ (root)`.
